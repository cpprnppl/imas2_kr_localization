# 아이돌마스터 2 (PS3, NPJB00337) 한글 패치 — 실기 설치 안내

## 들어 있는 것
- `USRDIR/resource/…` : 원본과 달라진 파일만 들어 있습니다.
  - 게임 리소스: UI 그림, 게임 데이터 문구, 메일, 라이브 가사 등
  - 스크립트(SCB, `gscript/…`)
  - 폰트(`im2_font*.nfh/.nut`)
  - 타이틀 데모(`scene/attract.mpc`)
- `manifest.json` : 파일마다 분류(res/scb/font/attract), 크기, SHA-256
- `SHA256SUMS.txt` : 같은 해시 목록(복사가 제대로 됐는지 확인용)

## 들어 있지 않은 것 (중요)
- **실행 파일(EBOOT.BIN)은 들어 있지 않습니다.** 게임에 원래 있는 EBOOT.BIN을 그대로 씁니다.
- 실행 파일 안에 박혀 있는 문구 **222개**는 실기에서 **일본어로 남습니다**. 시스템 확인창 일부와 일부 메뉴 문구가 여기 해당합니다.
  이 문구들은 에뮬레이터(RPCS3) 전용 패치로만 한글이 들어갑니다.
- 그 밖에 실행 파일 안의 Shift-JIS 문구 6개는 RPCS3에서도 일본어 그대로입니다.

## 준비
- 이 패치는 **본인이 정식으로 가지고 있는 PS3판 NPJB00337**에 덮어쓰는 리소스 교체 패치입니다.
- 게임이 설치된 위치: `/dev_hdd0/game/NPJB00337/USRDIR/`
- 파일 관리 도구(FTP, 파일 관리자 등)로 본체 HDD에 복사할 수 있어야 합니다.

## 설치 순서
1. **원본 백업**: 덮어쓸 파일을 먼저 PC 등에 백업합니다.
   목록은 `manifest.json`의 `path`와 같습니다(`USRDIR/resource/…`).
   백업 위치는 본체 밖을 권장합니다.
2. **복사**: 꾸러미의 `USRDIR` 폴더 내용을 본체 `/dev_hdd0/game/NPJB00337/USRDIR/`에 같은 경로 그대로 덮어씁니다.
   폴더 구조를 바꾸지 마세요. 예: `USRDIR/resource/gscript/…` → 본체 `…/USRDIR/resource/gscript/…`
3. **확인**(권장): 복사한 파일을 PC로 다시 가져와 `SHA256SUMS.txt`와 비교합니다.
   - Windows: `certutil -hashfile <파일> SHA256`
4. 게임을 실행해 타이틀·메인 메뉴·대사가 한글로 나오는지 봅니다.

## 되돌리기
- 1단계에서 백업한 원본 파일을 같은 경로에 다시 덮어씁니다.
- 백업이 없으면 게임 데이터 재설치로만 원복됩니다. 그러니 **백업을 꼭 먼저** 하세요.

## 알려진 점
- 이 꾸러미의 파일은 에뮬레이터(RPCS3)에서 배포·검증한 상태 그대로입니다. 실기에서 직접 확인한 것은 아닙니다.
  실기 확인 결과(정상·오류 화면)를 알려 주시면 반영합니다.
- 세이브 데이터는 건드리지 않습니다.
